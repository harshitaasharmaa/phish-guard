How Phishing Websites Deceive Users

Understanding heuristic warning signs that attackers use to craft fraudulent URLs.

Numeric IP Addresses

Legitimate services almost always use registered domain names. Attackers often use direct IPv4/IPv6 addresses (e.g., 192.168.1.5/login) to bypass domain registration checks.

having_ip_address

The "@" Symbol Trick

Browsers treat everything preceding an @ symbol in a URL as authentication credentials and ignore it, routing the user to the destination domain after the @.

having_at_symbol

Subdomains & Hyphen Prefixes

Phishers insert trusted brand names into subdomains or with hyphens (e.g. paypal-verify.com) to trick users who only glance at the start of the address.

prefix_suffix • having_sub_domain

Deceptive HTTPS Tokens

Phishers sometimes embed the text "https" directly into the hostname of an unencrypted HTTP link (e.g. http://https-secure-bank.org) to simulate security.

https_token

Model Architecture & Methodology

The backend uses an ensemble Random Forest Classifier trained on 30 discrete heuristics from the UCI Machine Learning Repository (Dataset #327). It achieves 97.56% accuracy on standard splits and 95.44% accuracy under strict group-isolated cross-validation (StratifiedGroupKFold).
